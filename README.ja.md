# giff

[English](./README.md) | 日本語

`giff` はターミナルで動く Git diff ビューアです。ワーキングツリーを監視して、差分をリアルタイムに表示します。

![giff screenshot](./docs/images/preview_1.png)

## インストール

macOS と Linux（amd64 / arm64）で動作します。

**homebrew (macOS / Linux):**

```console
$ brew install --cask sukechannnn/tap/giff
```

**go install:**

```console
$ go install github.com/sukechannnn/giff@latest
```

**ビルド済みバイナリ:**

[リリースページ](https://github.com/sukechannnn/giff/releases)から環境に合ったアーカイブをダウンロードして展開し、`giff` を `PATH` の通った場所に置いてください:

```console
$ tar -xzf giff_<version>_linux_amd64.tar.gz
$ sudo mv giff /usr/local/bin/
```

**ソースからビルド:**

```console
$ git clone https://github.com/sukechannnn/giff.git
$ cd giff
$ go build -o giff
```

## 使い方

```console
$ giff            # 現在の変更を表示
$ giff --watch    # ウォッチモード: ファイル変更時に自動更新
$ giff -v         # バージョン表示
```

### ファイルリスト

| キー | 操作 |
|------|------|
| `j` / `k` | カーソル移動 |
| `H` / `L` | ディレクトリの折りたたみ/展開 |
| `a` | ステージ/アンステージ |
| `d` | 変更を破棄 |
| `Ctrl+A` | 全ファイルをステージ |
| `Ctrl+K` | コミット |
| `Ctrl+J` | amend |
| `s` | Split View |
| `w` | 空白変更を非表示 |
| `/` | 差分を grep（マッチした変更行を持つファイルだけに絞り込み。ファイルブラウザではマッチした行を持つファイル） |
| `Ctrl+F` | ファイル名で絞り込み（glob・カンマ区切りの複数指定に対応） |
| `!` | パスで非表示 — `Ctrl+F` の逆（例: `generated,node_modules`） |
| `v` | $EDITOR で開く（`/` の grep 中は現在のヒット行で開く） |
| `c` | VS Code で開く（`/` の grep 中は現在のヒット行で開く） |
| `n` / `N` | 次/前の grep ヒット（`/` の grep 中） |
| `Ctrl+L` | Git ログ |
| `pr` | PR の差分（コミット・push 済みの変更も GitHub の PR と同じ形で表示） |
| `b` | ブランチの切り替え（ローカルのブランチと open な PR のブランチを、PR のタイトル付きで一覧表示。今のブランチの PR の base を辿ったものが先頭。PR のブランチは `gh pr checkout` で最新にして切り替え）。ファイルブラウザ（`f`）では、代わりに blame を表示/非表示（各行の左にその行を最後に変えたコミットを出し、カーソル行のコミットはステータスバーに出す） |
| `f` | ファイルブラウザ — Git で管理しているファイルを、カーソル位置のファイルを開いた状態で表示（もう一度 `f` で差分に戻る） |
| `I` | 差分ビューの `i` で残したコメントと答えの一覧 |
| `t` | ターミナルペインを開く — コマンドを実行、`Tab` で出力をスクロール |
| `Enter` | 差分ビューに切替 |
| `q` | 終了 |

### 差分ビュー

| キー | 操作 |
|------|------|
| `j` / `k` | カーソル移動 |
| `gg` / `G` | 先頭/末尾 |
| `V` | 行選択 |
| `a` | 選択行をステージ |
| `A` | ファイル全体をステージ/アンステージ |
| `/` | 検索 |
| `n` / `N` | 次/前の検索結果。`]` で単語を選んでいるときはその単語の次/前の出現箇所（`/` の grep 中はファイルをまたいで移動） |
| `]` / `[` | 単語単位でカーソルを移動（行末で次/前の行へ）し、その単語の出現箇所をすべてハイライト（`n` / `N` でたどる）。`Esc` で解除 |
| `l` / `h`（単語にいるとき） | `]` で選んだ単語を、間の記号ごと次/前の単語まで広げる（例: `scheduled` → `scheduled-ecs` → `scheduled-ecs-task`。単語にいないときは横スクロール） |
| `go` | `]` で選んだ単語の定義へジャンプ（`git grep` で探す。候補が複数あるときはコードのプレビュー付きの一覧から選ぶ。Terraform のモジュールの `source` の行ではモジュールのファイルを開く。[詳細](./docs/definition-jump.ja.md)） |
| `Ctrl+O` | `go` を押した場所に戻る |
| `i` | カーソル行（`V` で選んだときはその行）への質問や依頼をコメントとして残し、Claude Code に答えてもらう（[Claude Code に聞く](#claude-code-に聞く)）。コメントのある行では、そのコメントを開く・閉じる |
| `I` | カーソル行のコメントで Claude Code とチャットする（コメントのない行ではコメントの一覧） |
| `D` | カーソル行のコメントを削除 |
| `e` | 折りたたみ切替 |
| `s` | Split View |
| `w` | 空白変更を非表示 |
| `y` | 行をコピー。共通のインデントは除く（`]` / `[` で単語にいるときはその単語） |
| `Y` | ファイルパスをコピー |
| `f` | カーソル位置のファイル全体を表示（もう一度 `f` で差分に戻る） |
| `Ctrl+L` | `path:行番号` をコピー |
| `pr` | PR の差分 |
| `b` | ブランチの切り替え（ファイルブラウザでは blame の表示/非表示） |
| `Ctrl+F` | ファイル名で絞り込み（ファイルリストにフォーカスが移る） |
| `Ctrl+E` / `Ctrl+Y` | スクロール |
| `Esc` | ファイルリストに戻る |
| `q` | 終了 |

PR の差分（`pr`）と Git ログ（`Ctrl+L`）のコミットは読み取り専用です。ステージ・破棄・取り消し・Git ログと PR の差分を開く操作・ブランチの切り替え（`b`）以外は、上のキーがそのまま使えます。ファイル全体の表示（`f`）と定義へのジャンプ（`go`）は、ファイルがチェックアウト中のブランチのものである PR の差分では使えますが、Git ログでは使えません。PR の差分では、`r` で新しいコミットを反映できます。

## Claude Code に聞く

差分ビュー（ファイル表示でも）で `i` を押すと、GitHub のレビューコメントのように、カーソル行（`V` で選んだときはその行）の直下に入力欄が開き、その行への質問・依頼を書けます。`Enter` で、ファイル・行番号・その行のコードと一緒にコメントとして保存します（改行は `Shift+Enter`。`Shift+Enter` を `Enter` と区別できない端末では `Option+Enter`）。同じリポジトリで動かしている Claude Code がコメントを取りに行って答え、答えが届くと giff のステータスバーに出ます。

コメントのある行は行番号の横に印が付きます（答え待ちは黄色、答えが来たら緑）。その行で `i` を押すと、行の下にコメントと答えが全文で開きます（もう一度 `i` を押すか、カーソルが行を離れると閉じます。書いた直後のコメントも同じように開いたままです）。`I` を押すとチャットが開き、Claude Code と会話を続けられます。`Enter` で返信を送ると、Claude Code はそれまでのやり取りを踏まえて答え、答えは届きしだいチャットに出ます（`Tab` でチャット欄に移ってスクロール、`Esc` で閉じる）。`D` でその行のコメントを削除できます。コメントのない行で `I` を押すと、すべてのコメントの一覧を開けます（`Enter` でその行を表示、`i` でチャット、`D` で削除）。

最初に一度、Claude Code に `giff` スキルを入れます:

```console
$ giff comment install-skill
```

あとは giff で見ているリポジトリで Claude Code を起動して `/giff` を実行します。コメントを待ち受けて一つずつ答え（変更を頼まれたら変更して）、答えを giff に返します。

コメントは `~/.giff/comments` に、リポジトリ（worktree）ごとに別のファイルで保存します。Claude Code は自分が作業しているリポジトリのコメントしか見ません。`giff comment` でコマンドラインからも扱えます:

```console
$ giff comment list [--all]       # まだ答えのないコメント（--all: 答えたものも）
$ giff comment next [--wait 10]   # 次のコメントを JSON で取り出す（なければ10分待つ）
$ giff comment next --forever     # 同じく、届くまで待ち続ける（スキルが使う）
$ giff comment answer <id>        # コメントに答える（答えは標準入力から）
$ giff comment reply <id>         # 答えに返信する（標準入力から）
$ giff comment rm <id>            # コメントを削除
$ giff comment clear [--all]      # 答えたコメントを削除（--all: すべて）
```
